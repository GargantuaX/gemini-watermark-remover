# 水印去除算法研究摘要

本文件保留研究结论。详细实验流水账已转为本地归档；本文不是当前代码或发布质量的验收凭证。

## 保留的设计原则

- 先确认水印尺寸、锚点、alpha形状与强度，再改变去除策略；不以放宽保护阈值代替定位研究。
- 不同候选使用独立的来源、残留和内容损伤证据比较。候选用自身模板得到的低残留分数不能证明输出干净。
- 对白色alpha模板保留有符号的正向来源证据，避免把深色结构误当水印后产生黑洞。
- 亚像素搜索、边缘清理和补绘必须由受控样本及独立验证支持，不能直接把离线拟合最优值当生产默认。
- 输入可处理时保留best-effort输出；质量不确定性作为非阻塞信息呈现。

## 验证与后续研究

对确定来源的原始输出按几何和背景分组，保存前后对照；以已知背景、无水印控制、错模板反例及未参与调参的样本检查收益和损伤。
研究中的失败或局部改善不能推广为全体输入结论。具体代码以 `src/core/` 为准，发布证据见 `release/evidence/`，审查状态见 [审查台账](code-review-log.md)。
