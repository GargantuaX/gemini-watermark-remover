## 已定位并修正的错位分支

`clean-skip-04` 和 `clean-skip-05` 是两张 1024×1024 图片：

- 真正的白色水印在 `(880, 880)`，尺寸 48×48，右下边距各 96px。
- 自动选择器将 `(929, 929)` 的背景细节识别成 36px V2 水印；固定选择器没有选中候选。
- 这个 V2 候选使流程提前确认水印存在，因此跳过独立的 exact-48 源图证据补救。结果保留原水印，同时在背景上制造深色三角形。
- 两张原图在真实锚点上的空间相关性约 0.185/0.195，梯度相关性约 0.548/0.542，均具有正向白色证据和明显的局部边缘峰值。

修复只在固定选择器未选中、自动选择器选中 36px V2 时补做已有 exact-48 验证；仅当原有带符号源图及诱饵位置门槛通过、且两者几何位置不兼容时，转入既有 0.6 增益的补救流程。没有放宽证据门槛、移除极性保护或增加修补算法。

两张真实样本的右下 480×480 裁剪已加入测试夹具。回归测试在修复前选错位置而失败，修复后通过；它还检查背景误识别区域逐像素不变，以及真实水印核心确实得到处理。另有空白/暗色旧锚点的 V2 保留控制。

离线重跑同一批 69 张，只有这两张输出变化，其余 67 张逐像素一致。目视检查显示背景误伤消失、真实水印明显减弱，但中心仍有少量残留，不能标记为完全清除。

## 2026-09-10：两例内容误识别复核

扩大到完整原图及右下 600×600 区域后，`clean-skip-09` 与 `position-41` 均没有足够的可见证据支持此前“留下真实水印”的判断。可以确认的退化是：处理在望远镜旁的木质物体上制造黑洞，在玩偶额头上制造星形痕迹。此前的水印定位描述予以撤回，不能据此移动或加强去除。

- `clean-skip-09`：R192 的弱候选触发补救后，R64 标准候选凭更高的空间相关性获胜，但原图梯度相关性为负（约 -0.0215）。替换候选没有提供新的定位证据，却直接执行了白色模板逆运算。现在这个替换分支需要正向原图边缘相关性，否则不将它视为有效补救；保留 #142 的正向边缘证据路径。
- `position-41`：未确认存在水印时，经过局部细化的预览候选仍凭处理后的分数进入 best-effort。在该位置，原图的模板边缘匹配还不如附近偏移的模板。现在只对这一未确认、局部细化的预览补救分支检查附近 8 个模板偏移，要求所选位置是正向梯度匹配峰值。
- 第一版更宽泛的 R192 空间百分位限制被放弃：它影响了 `position-46` 中可见的真实水印，也破坏了 #142 的已有行为。没有将它纳入生产代码。
- 两张内容样本加入回归夹具，要求原图保持逐像素不变。向同一背景合成已知白色水印后，仍须能够处理并降低水印区域误差。

收窄后的离线验证覆盖 69 张冻结样本和另外 15 张预览／标准候选样本；只改变上述两张，其余 82 张逐像素不变。材料位于 `.artifacts/disjoint-review-20260910/`。这是有针对性的 84 张对照，不能称为最终 424 张发布验收。
