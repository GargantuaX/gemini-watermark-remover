# Issue #153：2752×1536 JPEG 的固定 48px 水印

用户反馈：[Watermark removal fails on newly generated Gemini images](https://github.com/GargantuaX/gemini-watermark-remover/issues/153)。
样本：[原始 JPEG](https://github.com/user-attachments/assets/4cad7bb1-fbb8-4c56-8d69-e1a4ed4fa536)。

## 复现与修复

1.0.41 在此图选择 `(2472,1256,88,88)` 的暗色背景，却未覆盖真正的白色星标。局部几何扫描表明，已有默认 48px 模板在右/下边距 89px 时与源图高度吻合：空间相关性 0.9976、梯度相关性 0.9936。无需新增 alpha 模板。

仅对 `2752×1536` 增加这个固定候选。新候选与旧 96px 星标区域重叠，直接加入普通候选会让两个旧样本测试失败；因此仅在正向空间分数 ≥0.95、梯度分数 ≥0.8 且非 dark-polarity 时允许采用。其他目录、候选排序规则与处理强度不变。不把一个 JPEG 的边距推广到其他分辨率或整个 Gemini 产品线。

修复后选中 `(2615,1399,48,48)`，沿用既有 gain 0.6。实际输出的星标核心平均 RGB 为 `(32.78,17.14,9.97)`，邻近背景为 `(33.48,16.31,9.33)`；ROI 之外的解码像素没有变化。放大后仍可见轻微压缩/边缘纹理，不以候选自身的 `clean` 评分代替视觉检查。

## 回归证据

`tests/fixtures/issue153-2752x1536-r89.png` 是原始 JPEG 解码后的右下 480×480 裁剪。测试恢复完整画布尺寸，覆盖错误候选和真正星标的位置，验证正确选择、错误位置不变，以及冻结的星标核心与背景颜色接近。

负向验证与修复前 HEAD 逐像素比较了 12 组输入，输出均一致：

- 三种亮度的无水印纯色图和一张无水印纹理图。
- 新位置上的暗色星形内容。
- 2752×1536、2751×1536、2753×1536、2816×1536、1536×2752 的旧 canonical 96px 水印。
- 真实旧样本 `20260616.png` 和 `20260729-issue118.png`。

自动测试额外验证 strong catalog gate 拒绝空白与暗色内容，并保留正向白色星标。该验证不代表广泛新图片的留出集，发布后的新样本仍需持续核对。
